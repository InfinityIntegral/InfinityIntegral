# Languages and tools

For my personal projects, I like using C++ 20 with CMake build system, possibly with the inclusion of compatible libraries. C++ is by far my favourite language because it has so many features. Just to name a few, you can write templates that take a different number of parameters, unions which allow multiple objects to share the same memory space, ::operator new and placement new to separate memory allocation and actually constructing the object. And most important for last, you get direct access to memory using raw pointers.

Although I prefer C++ by far, I also can code in GLSL, Java, C#, Python, and JavaScript, just that I occasionally would need searching online for the syntax. I also plan to learn HLSL in the near future.

Since the C++ Standard Library is quite annoying to use and take forever to lint, I am building SGEXTN, my own library intended to replace it and add capabilities such as the display of GUI and proper interaction with mobile file systems.
